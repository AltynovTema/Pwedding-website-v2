# Свадебный сайт-приглашение | Артём & Алёна

Современный адаптивный свадебный сайт с элегантным дизайном для свадьбы 9 августа 2026 года.

## 📋 Описание

Профессиональный свадебный сайт с полным функционалом:
- Главный экран с таймером обратного отсчёта
- История любви пары с фотографиями
- Детали мероприятия (дата, место, дресс-код)
- Программа дня с расписанием
- Фотогалерея
- Форма подтверждения участия (RSVP)
- Пожелания по подаркам
- Контактная информация

## 🚀 Быстрый старт

## ✨ Функциональность

### Таймер обратного отсчёта
Автоматически считает дни, часы, минуты и секунды до свадьбы (9 августа 2026, 15:00)

### Анимации при скролле
Элементы плавно появляются при прокрутке страницы с помощью Intersection Observer API

### RSVP форма
Форма подтверждения участия с:
- Валидацией email
- Проверкой обязательных полей
- Модальным окном успеха
- Готовностью к подключению backend

### Адаптивная навигация
- Десктоп: горизонтальное меню с подсветкой активной секции
- Мобильные: гамбургер-меню с плавной анимацией
- Умное скрытие/показ при скролле

### Дополнительные возможности
- Экран загрузки с инициалами пары
- Кнопка "Наверх" с плавной прокруткой
- Фотогалерея с hover-эффектами
- Параллакс фон на главном экране
- Интеграция с календарём (iCal)
- Оптимизированные изображения с lazy loading
- Кастомный скроллбар в стиле сайта
- Стили для печати

## 📝 Редактирование контента

Все тексты и данные хранятся в файле `data/content.json`. Это единственный файл, который нужно редактировать для обновления контента!

### Изменение имён пары

```json
"couple": {
  "groom": "Артём",
  "bride": "Алёна"
}
```

### Изменение даты свадьбы

```json
"wedding": {
  "date": "2026-08-09",
  "displayDate": "09 Августа 2026",
  "fullDateTime": "August 9, 2026 15:00:00"
}
```

### Изменение места проведения

```json
"venue": {
  "name": "Усадьба \"Серебряный Век\"",
  "address": "Московская область, д. Жуковка"
}
```

### Изменение программы дня

```json
"schedule": [
  {
    "time": "15:00",
    "title": "Сбор гостей",
    "description": "Welcome-фуршет"
  }
]
```

### Изменение контактов

```json
"contacts": {
  "groom": {
    "phone": "+7 (900) 123-45-67"
  },
  "bride": {
    "phone": "+7 (900) 123-45-68"
  }
}
```

### Замена фотографий

1. Поместите фото в папку `media/photos/`
2. Обновите пути в `data/content.json`:

```json
{
  "title": "Первая встреча",
  "description": "Наша история...",
  "image": "./media/photos/photo1.jpg"
}
```

## 🐛 Решение проблем

### Сайт не запускается

1. Проверьте установку Node.js: `node --version`
2. Удалите `node_modules` и выполните `npm install` заново
3. Проверьте порт 3000 - он должен быть свободен

```bash
rm -rf node_modules
npm install
npm run dev
```

### Стили не применяются

1. Проверьте подключение Tailwind CDN
2. Очистите кэш браузера (Ctrl+Shift+R / Cmd+Shift+R)
3. Проверьте консоль браузера на ошибки (F12)

### Таймер не работает

1. Проверьте формат даты в `data/content.json`
2. Убедитесь, что элемент с id="countdown" существует
3. Проверьте консоль на ошибки JavaScript

### Изменения не видны

1. Сохраните файл (Ctrl+S / Cmd+S)
2. Браузер должен обновиться автоматически (HMR)
3. Если нет - обновите страницу вручную (Ctrl+R / Cmd+R)
