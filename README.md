# Wedding Invitation Website - Артём & Алёна

Свадебный сайт-приглашение для Артёма и Алёны | 09.08.2026

## 📋 Описание

Современный адаптивный свадебный сайт с элегантным дизайном, включающий:
- Главный экран с таймером обратного отсчёта
- История любви пары
- Детали мероприятия (дата, место, дресс-код)
- Программа дня
- Форма подтверждения участия (RSVP)
- Пожелания по подаркам
- Контактная информация

## 🚀 Начало работы

### Установка зависимостей

```bash
npm install
```

### Запуск локального сервера разработки

```bash
npm run dev
```

Сервер запустится на http://localhost:3000

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы появятся в папке `dist/`

### Предпросмотр продакшен-сборки

```bash
npm run preview
```

## ✨ Функциональность

### Таймер обратного отсчёта
Автоматически считает дни, часы, минуты и секунды до свадьбы (9 августа 2026, 15:00)

### Анимации при скролле
Элементы плавно появляются при прокрутке страницы с помощью Intersection Observer API

### RSVP форма
Форма подтверждения участия с валидацией и модальным окном успеха

### Адаптивная навигация
- Десктоп: горизонтальное меню
- Мобильные: гамбургер-меню

### Эффекты
- Параллакс фон на главном экране
- Hover эффекты на карточках истории
- Плавная прокрутка между секциями
- Изменение навбара при скролле

## 📱 Адаптивность

Сайт полностью адаптирован для:
- Десктопов (1920px+)
- Планшетов (768px - 1024px)
- Мобильных устройств (320px - 767px)
