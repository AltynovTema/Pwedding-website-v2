# Руководство по замене фотографий

## 📸 Как заменить фотографии

### Шаг 1: Подготовьте фотографии
- Формат: JPG или PNG (JPG рекомендуется для фото)
- Рекомендуемые размеры:
  - Главный фон (Hero): 1920x1080px
  - Фото истории/галереи: 800x600px или 1200x800px
  - Фото места проведения: 1200x800px

### Шаг 2: Назовите файлы
Используйте эти точные имена файлов:

| Файл | Где появляется | Рекомендуемый размер |
|------|----------------|------------------|
| `hero-bg.jpg` | Главный фон сайта | 1920x1080px |
| `story-1.jpg` | Первая карточка истории | 800x600px |
| `story-2.jpg` | Вторая карточка истории | 800x600px |
| `story-3.jpg` | Третья карточка истории | 800x600px |
| `venue.jpg` | Фото места проведения | 1200x800px |
| `gallery-1.jpg` | Фото галереи 1 | 800x800px |
| `gallery-2.jpg` | Фото галереи 2 | 800x800px |
| `gallery-3.jpg` | Фото галереи 3 | 800x800px |
| `gallery-4.jpg` | Фото галереи 4 | 800x800px |

### Шаг 3: Скопируйте файлы
Просто скопируйте ваши фотографии в эту папку `images/` с именами, указанными выше.

### Шаг 4: Обновите браузер
Сайт автоматически использует ваши новые фотографии!

## 💡 Советы

- **Размер файлов до 500KB** для быстрой загрузки
- **Используйте формат JPG** для фотографий (меньший размер файла)
- **Используйте формат PNG** только если нужна прозрачность
- **Сжимайте фотографии** перед добавлением (используйте tinypng.com или аналоги)
- **Сохраняйте пропорции** чтобы избежать искажений

## 🎨 Опционально: Добавить больше фото в галерею

Чтобы добавить больше фотографий в галерею:

1. Назовите их `gallery-5.jpg`, `gallery-6.jpg` и т.д.
2. Откройте `index.html`
3. Найдите секцию Галереи (поиск по `<!-- Photo Gallery Section -->`)
4. Скопируйте один из существующих блоков галереи и вставьте его
5. Измените номер в имени файла

Пример:
```html
<div class="aspect-square overflow-hidden rounded-lg shadow-lg hover:shadow-2xl transition-shadow duration-300 fade-in">
    <img src="./images/gallery-5.jpg" alt="Фото 5" loading="lazy" class="w-full h-full object-cover hover:scale-110 transition-transform duration-500">
</div>
```

## 🔧 Если фотографии не отображаются

1. Проверьте, что имена файлов совпадают точно (регистр важен!)
2. Убедитесь, что файлы находятся в папке `images/`
3. Очистите кэш браузера (Ctrl+Shift+R / Cmd+Shift+R)
4. Проверьте консоль браузера (F12) на ошибки
