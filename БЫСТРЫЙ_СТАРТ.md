## ⚡ Три шага для запуска

### Шаг 1: Установить зависимости

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

*(Это установит Vite - инструмент для разработки)*

### Шаг 2: Запустить сервер разработки

```bash
npm run dev
```

Браузер откроется автоматически на http://localhost:3000

### Шаг 3: Начать редактирование контента

Откройте файл `data/content.json` и замените тексты из старого проекта!

## 📝 Как перенести контент из старого проекта (Priglos)

### 1. Откройте два файла рядом:
- Старый проект: `/Users/artem/My_files/Info_Tec/My_Project/Priglos/...`
- Новый проект: `data/content.json`

### 2. Скопируйте из старого проекта:
- ✅ Тексты приглашения
- ✅ Информацию о месте проведения
- ✅ Дату и время свадьбы
- ✅ Программу мероприятия
- ✅ Контактные данные
- ✅ Историю знакомства

### 3. Вставьте в `data/content.json`:

Найдите соответствующий раздел и замените текст.

**Пример:**

Было:
```json
"venue": {
  "name": "Усадьба \"Серебряный Век\"",
  "address": "Московская область, д. Жуковка, Рублёвское шоссе"
}
```

Стало (ваше):
```json
"venue": {
  "name": "Ваше место проведения",
  "address": "Ваш адрес"
}
```

## 🎨 Что можно легко изменить?

### В файле `data/content.json`:

#### 👰 Имена пары
```json
"couple": {
  "groom": "Артём",      // ← Изменить имя жениха
  "bride": "Алёна"       // ← Изменить имя невесты
}
```

#### 📅 Дата свадьбы
```json
"wedding": {
  "displayDate": "09 Августа 2026",     // ← Для отображения
  "fullDateTime": "August 9, 2026 15:00:00"  // ← Для таймера
}
```

#### 🏰 Место проведения
```json
"venue": {
  "name": "Название места",
  "address": "Полный адрес"
}
```

#### 📞 Контакты
```json
"contacts": {
  "groom": {
    "phone": "+7 (XXX) XXX-XX-XX"   // ← Телефон жениха
  },
  "bride": {
    "phone": "+7 (XXX) XXX-XX-XX"   // ← Телефон невесты
  }
}
```

#### 📋 Программа дня
```json
"schedule": [
  {
    "time": "15:00",                    // ← Время
    "title": "Сбор гостей",             // ← Название
    "description": "Описание события"   // ← Описание
  }
  // ... добавьте или измените пункты
]
```

#### 💕 История любви
```json
"story": [
  {
    "title": "Первая Встреча",          // ← Заголовок
    "description": "Текст истории...",  // ← Описание
    "image": "ссылка-на-фото.jpg"       // ← URL фото
  }
  // ... добавьте свои истории
]
```

## 🖼️ Как заменить фотографии?

### Вариант 1: Использовать внешние ссылки
Загрузите фото на хостинг (например, imgur.com) и вставьте ссылку:
```json
"image": "https://example.com/my-photo.jpg"
```

### Вариант 2: Локальные файлы (рекомендуется)
1. Создайте папку `images/` в корне проекта
2. Положите туда фотографии
3. Укажите путь:
```json
"image": "./images/my-photo.jpg"
```

## 🎯 Основные секции сайта

1. **Hero (Главный экран)** - Большое фото пары + имена + дата
2. **Countdown (Таймер)** - Обратный отсчёт до свадьбы

7. **RSVP (Подтверждение)** - Форма для гостей
8. **Footer (Контакты)** - Телефоны для связи

## 🔧 Если что-то сломалось

### Сайт не открывается?
```bash
# Остановите сервер (Ctrl+C)
# Переустановите зависимости
rm -rf node_modules
npm install
npm run dev
```

### Изменения не видны?
- Сохраните файл (Ctrl+S / Cmd+S)
- Обновите браузер (Ctrl+R / Cmd+R)
- Проверьте консоль браузера (F12) на ошибки

### Таймер показывает неправильное время?
Проверьте формат даты в `data/content.json`:
```json
"fullDateTime": "August 9, 2026 15:00:00"  // ← Формат: Месяц День, Год Часы:Минуты:Секунды
```

## 📱 Проверка на мобильных

В браузере Chrome:
1. Нажмите F12 (открыть DevTools)
2. Нажмите Ctrl+Shift+M (Cmd+Option+M на Mac)
3. Выберите устройство (iPhone, iPad, etc.)
4. Проверьте, как выглядит сайт

## 🚀 Публикация сайта (когда всё готово)

### Простой способ - Netlify (бесплатно)

1. Соберите проект:
   ```bash
   npm run build
   ```

2. Зайдите на netlify.com

3. Перетащите папку `dist/` на сайт

4. Получите ссылку вида: `your-wedding.netlify.app`

### Продвинутый способ - GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите файлы проекта
3. Включите GitHub Pages в настройках
4. Сайт будет доступен бесплатно
