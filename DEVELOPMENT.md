# Руководство по разработке свадебного сайта

## 📦 Установка и запуск

### 1. Установите зависимости
```bash
npm install
```

### 2. Запустите сервер разработки
```bash
npm run dev
```

Сайт откроется автоматически в браузере на http://localhost:3000

## 🎯 Быстрый старт

### Изменение основного контента

Все данные сайта хранятся в файле `data/content.json`. Вы можете легко изменить:

#### 1. Имена пары
```json
"couple": {
  "groom": "Артём",
  "bride": "Алёна"
}
```

#### 2. Дата свадьбы
```json
"wedding": {
  "date": "2026-08-09",
  "displayDate": "09 Августа 2026",
  "fullDateTime": "August 9, 2026 15:00:00"
}
```

#### 3. Место проведения
```json
"venue": {
  "name": "Усадьба \"Серебряный Век\"",
  "address": "Московская область, д. Жуковка"
}
```

#### 4. Программа дня
```json
"schedule": [
  {
    "time": "15:00",
    "title": "Сбор гостей",
    "description": "Welcome-фуршет"
  }
]
```

#### 5. Контакты
```json
"contacts": {
  "groom": {
    "phone": "+7 (900) 123-45-67"
  }
}
```

## 🎨 Стилизация

### Цветовая схема

Цвета определены в `tailwind.config` внутри `index.html`:

```javascript
colors: {
  coral: '#7D2826',   // Коралловый (акценты)
  candle: '#EFE9D7',  // Кремовый (фон)
  leaf: '#898861',    // Оливковый (вторичный)
  juniper: '#343723', // Тёмно-зелёный (текст)
  gold: '#D4AF37',    // Золотой (декор)
}
```

### Шрифты

Используются два шрифта из Google Fonts:
- **Playfair Display** - для заголовков
- **Montserrat** - для основного текста

Изменить можно в `styles/main.css`

## 📝 Редактирование секций

### Hero Section (Главный экран)
Файл: `index.html`, строки ~64-109

Изменить фоновое изображение:
```css
.hero-bg {
  background-image: url('your-image-url.jpg');
}
```

### История любви
Файл: `index.html`, строки ~136-179

Добавить/изменить историю:
```html
<div class="group relative overflow-hidden rounded-lg shadow-xl fade-in">
  <img src="your-image.jpg" alt="Описание">
  <div class="absolute inset-0 bg-juniper/60 flex items-center justify-center">
    <h3>Заголовок</h3>
    <p>Описание</p>
  </div>
</div>
```

### Детали мероприятия
Файл: `index.html`, строки ~181-231

Изменить информацию о месте, времени, дресс-коде.

### Программа дня
Файл: `index.html`, строки ~233-299

Добавить новый пункт программы:
```html
<div class="relative pl-8 md:pl-0 fade-in">
  <div class="md:flex md:justify-between md:items-center">
    <div><span class="text-3xl font-bold font-serif text-gold">ВРЕМЯ</span></div>
    <div>
      <h3>Название</h3>
      <p>Описание</p>
    </div>
  </div>
</div>
```

## 🔧 Продвинутые настройки

### Добавление новых шрифтов

1. Выберите шрифт на https://fonts.google.com
2. Скопируйте ссылку для подключения
3. Добавьте в `<head>` в `index.html`

Рекомендуемые размеры:
- Hero background: 1920x1080px
- Story images: 800x600px
- Venue image: 1200x800px

Форматы: WebP (предпочтительно) или JPG

### SEO оптимизация

Добавьте meta-теги в `<head>`:
```html
<meta name="description" content="Свадьба Артёма и Алёны - 9 августа 2026">
<meta property="og:title" content="Свадьба Артёма и Алёны">
<meta property="og:image" content="path-to-image.jpg">
```

## 🐛 Решение проблем

### Сайт не запускается

1. Проверьте установку Node.js: `node --version`
2. Удалите `node_modules` и выполните `npm install` заново
3. Проверьте порт 3000 - он должен быть свободен

### Стили не применяются

1. Проверьте подключение Tailwind CDN
2. Очистите кэш браузера (Ctrl+Shift+R / Cmd+Shift+R)
3. Проверьте консоль браузера на ошибки

### Таймер не работает

1. Проверьте формат даты в `scripts/main.js`
2. Убедитесь, что элемент с id="countdown" существует
3. Проверьте консоль на ошибки JavaScript

## 📱 Тестирование

### Проверка адаптивности

В Chrome DevTools (F12):
1. Нажмите Ctrl+Shift+M (Cmd+Option+M на Mac)
2. Выберите разные устройства
3. Проверьте отображение на мобильных

### Основные breakpoints

- Mobile: 320px - 767px
- Tablet: 768px - 1023px
- Desktop: 1024px+

## 🚀 Деплой (публикация)

### Вариант 1: GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите файлы проекта
3. Включите GitHub Pages в настройках
4. Сайт будет доступен по адресу username.github.io/repo-name

### Вариант 2: Netlify

1. Зарегистрируйтесь на netlify.com
2. Перетащите папку `dist` после `npm run build`
3. Получите бесплатный хостинг

### Вариант 3: Vercel

1. Установите Vercel CLI: `npm i -g vercel`
2. Выполните: `vercel`
3. Следуйте инструкциям
